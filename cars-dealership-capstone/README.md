# Cars Dealership Capstone Project

## Repository Name
`cars-dealership-capstone`

## Project Name
**Cars Dealership — Full-Stack Development Capstone**

## Project Overview
A responsive web application for a national car retailer in the United States. The application is designed to let visitors browse dealership branches, view dealership details, and read or submit customer reviews.

## Technology Stack
- Frontend: React, HTML, CSS, JavaScript
- Backend: Django / Django REST Framework, with supporting services as required by the course labs
- Data storage: SQLite and/or MongoDB depending on service requirements
- API testing: cURL
- Version control and CI/CD: Git and GitHub Actions
- Containerization and deployment: Docker and IBM Cloud Code Engine

## Core Features
- Browse dealers and filter dealers by state
- View details for an individual dealership
- Register, log in, and log out
- Read and submit dealership reviews
- Analyze review sentiment
- Retrieve dealership and car make/model information through API endpoints
